# Pre-Deploy Rationalizations

| Excuse | Reality |
| --- | --- |
| “The previous commit was green.” | Evidence belongs to a commit; run against current `HEAD`. |
| “This is configuration only.” | Configuration can remove bindings, routes, or secrets. |
| “The VP said ship.” | Authority accepts consequences; it does not make unchecked code safe. |
| “Only one test is failing.” | One failure is a NO-GO until understood and fixed. |
| “Production will tell us quickly.” | Production traffic is not a test harness. |
